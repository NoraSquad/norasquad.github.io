FAQ

Which Unity versions and render pipelines are supported?

Unity 2022.3 LTS or newer, including Unity 6. The materials work in the Universal Render Pipeline and the Built-in Render Pipeline without conversion.

Can I combine several packs in one project?

Yes. All packs share the same folders and scripts, so importing a second pack adds its characters next to the first. The demo scenes find every Nora Squad character in your project automatically.

Can I use my own animations or Animator Controller?

Yes. The characters use a Generic rig and the clips are regular animation clips. Keep the NoraCharacter component (or any script with OnHit() / OnSkill()) to receive the impact events.

Do I need the demo effects?

No, they only show where the impact events fire. Use Tools ▸ Nora Squad ▸ Demo Effects to disable them or remove them from the project without leaving missing references.

I own the Starter pack. What happens when I buy a themed pack?

Import it into the same project. Shared files are identical, so nothing breaks and the new characters appear in the demo scenes.
